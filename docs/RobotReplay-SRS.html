1文档目的

本文规定机器人三维复现与数据分析工具桌面端应提供的功能、输入输出、运行限制和验收标准，作为需求评审、软件设计、测试和交付的依据。

软件面向机器人研发、测试和现场支持人员。用户可以用关节与姿态 CSV 复现 X30、M20 和 DR02 的运动过程，查看数据曲线，收集远程设备日志，并对多个日志文件进行合并、筛选和导出。

2范围

2.1范围内

  • 桌面主程序的首页、导航、页面切换和文件管理。
  • X30 四足机器人、M20 轮足机器人和 DR02 人形机器人的独立三维复现。
  • 关节显示和手动调节、视角、截图与录像；X30 还支持地形回放。
  • 固定数据分析、自定义波形分析和配置保存。
  • 连接设备收集日志，以及本地日志的合并、筛选、搜索、统计与导出。
  • Windows x64 安装包及软件运行所需文件。
Web 说明：Web 端提供与桌面端相同的三维复现和数据查看功能；当桌面端 PyBullet 渲染不够流畅时，可使用浏览器端渲染，具体 Web 实现不在本文展开。

3需求分类与编号

3.1需求分类

需求类别说明覆盖主题
三维复现机器人离线问题复现需要X30、M20 和 DR02 的动作与姿态显示；X30 关节力矩和地形显示
数据分析研发数据排查需要固定模板分析、自定义波形、时间区间定位与导出
日志管理现场日志排查需要SSH 收集、远程预览、本地合并筛选与统计
安装交付离线交付与客户环境需要Windows 安装、免系统 Python、资源随包交付
产品功能桌面端功能定义界面行为、数据格式、功能边界和运行限制
用户操作用户操作要求操作流程、输入文件要求和机型功能差异

3.2需求编号

FR-* 表示功能需求，NFR-* 表示性能、可靠性等质量要求，IR-* 表示数据和接口要求，G-* 表示关键验收指标。优先级分为“必须”和“应该”，具体验收方式见第 10 章。

功能需求编号按“FR－功能字母－序号”组成。例如 FR-P04 表示第 4 条数据播放需求。

功能字母白话说明对应内容
N页面与切换首页、导航、进入和离开功能页。
E三维显示加载并显示 X30、M20、DR02 模型。
P数据播放加载 CSV，播放、暂停、跳转和调速。
T地形X30 地形文件加载和同步显示。
V三维操作与输出关节调节、视角、透明度、截图和录像。
A固定数据分析按规定好的项目显示数据曲线。
W自定义波形用户自己选择数据列并绘制曲线。
C日志收集连接设备、查看并下载日志。
L日志分析合并、筛选、搜索、统计和导出日志。
G配置与交付保存配置、统一版本号和制作安装包。

NFR 后面的字母单独表示质量要求：P 为性能、R 为可靠性、C 为兼容性、S 为安全性、U 为易用性、M 为便于维护。因此 FR-P 是“数据播放”，NFR-P 是“性能”，应结合前缀判断。

需求表中的“来源”也使用简写：BR 为业务需求，IM 为现有实现整理，UM 为用户操作需求；“验证”列中 D 为现场操作确认，T 为测试，I 为检查文件或交付物，A 为分析评审。

4术语与缩略语

术语定义
CSV用逗号分隔各列的文本数据文件。本工具用它保存关节、姿态、地形和分析数据。
IMU机器人姿态数据，包括横滚、俯仰和偏航三个方向。
三维复现按 CSV 中记录的数据逐帧显示机器人动作，不计算新的控制结果。
快照 CSV文件前部带有设备信息和数据列名的一种 CSV。
日志收集连接远程设备并把所选日志下载到本地。
日志分析把多个本地日志按时间合并，再进行筛选、搜索、统计和导出。

5运行环境与约束

5.1目标环境

项目要求
操作系统Windows 10 或更高版本，x64。
图形环境能够正常显示三维画面的显卡和驱动。
安装内容安装包包含主程序、三维服务、日志连接服务、图片支持和机器人模型。
其他软件用户无需另外安装 Qt、Python 或开发工具。
网络三维功能只使用本机连接；日志收集要求电脑能够连接目标设备。

5.2约束与假设

  • X30、M20 与 DR02 各自使用独立的三维服务，同一时间最多运行一个。
  • DR02 按其人形 URDF 的 31 个可动关节显示，不使用 X30 或 M20 的关节编号和播放数据。
  • 三维复现直接使用输入数据，不做插值、平滑或自动修正。
  • 地形只支持 X30；M20 的四个轮关节只支持手动调节。
  • 主机信息和波形配置保存在本地，运行账户必须能写入配置目录。
  • 输入文件必须符合第 8 章格式；格式错误时系统显示原因并保持可操作，不自动修改原始文件。

7非功能需求

7.1性能（NFR-P）

编号需求描述优先级验证
NFR-P01关节数据应按 200 Hz 名义采样率解释；速度档通过帧等待间隔调整，不修改数据内容。必须T
NFR-P02主程序与三维服务只传递播放操作和当前状态，不传递视频画面。必须I
NFR-P03加载大型 CSV 时应分段读取，只保留分析需要的数据列，并显示加载状态。必须T
NFR-P04一次加载多条曲线时，界面不得重复刷新造成明显卡顿；播放时只更新当前可见图表。应该I
NFR-P05录像期间界面应保持可操作；等待写入的画面最多保留 12 帧，超过时记录丢帧数量。必须T

7.2可靠性（NFR-R）

编号需求描述优先级验证
NFR-R01退出程序或离开功能页面后，该页面启动的三维服务或 SSH 服务必须同时关闭。必须T
NFR-R02一条消息分多次到达或多条消息同时到达时，主程序与本地服务仍应完整、按顺序处理。必须T
NFR-R03文件取消选择、路径失效、缺列、空文件、网络断开和写盘失败均应转化为可见错误，不得导致主界面崩溃或不可操作。必须T
NFR-R04停止录像后应完成剩余画面写入，使视频时长与实际录制时长一致；文件接近 1.9 GB 时应停止并提示用户。必须T
NFR-R05日志与波形配置文件损坏时应拒绝或忽略无效内容，不得影响其他模块启动。应该T

7.3兼容性与部署（NFR-C）

编号需求描述优先级验证
NFR-C01本版本支持 Windows x64，不要求支持其他操作系统。必须I
NFR-C02安装包应包含主程序、三维服务、SSH 服务和 X30、M20、DR02 三套机器人模型，用户无需安装开发环境。必须I
NFR-C03程序应可在常见 1366×768 笔记本可用区域内操作；控制面板和关节面板应通过滚动避免内容被裁切。必须D
NFR-C04快照 CSV 与普通 CSV 均应支持 UTF-8 列名；应用中文界面与 Windows 版本资源不得出现编码乱码。必须I

7.4安全性（NFR-S）

编号需求描述优先级验证
NFR-S01三维服务和 SSH 服务只允许本机主程序连接，端口由系统自动分配。必须I
NFR-S02远程文件预览中由用户控制的路径和关键字必须安全引用；不得因特殊字符拼接出额外命令。必须T
NFR-S03主机密码保存在本地配置文件中，配置目录必须限制为当前用户访问，并在用户手册中说明。必须I
NFR-S04首次连接设备时，界面应明确提示设备身份确认方式，不得在用户不知情的情况下信任未知设备。应该A

7.5可用性与可维护性（NFR-U/M）

编号需求描述优先级验证
NFR-U01各长耗时操作应显示状态、进度或日志，用户能够判断当前处于加载、播放、暂停、完成或错误状态。必须D
NFR-U02文件对话框、确认框与浮动分析窗口不得被三维覆盖窗口压在后方。必须T
NFR-M01三维复现、数据分析、波形分析、日志收集和日志分析应由独立模块完成，一个模块修改不得影响无关页面。应该A
NFR-M02生成安装包前必须检查主程序、图片支持、三维服务、SSH 服务和机器人模型是否齐全；缺少任一项时停止打包。必须I

8接口与数据需求

编号接口/数据需求验证
IR-01主程序 → 三维服务应能发送加载、播放、暂停、恢复、停止、跳转、速度、循环、关节和视角操作。T
IR-02三维服务 → 主程序应返回服务状态、当前帧、总帧数、12 路关节值、运行日志和错误信息。T
IR-03关节 CSV必须包含 Joint Pos 0..11 与 IMU roll/pitch/yaw；三维力矩着色使用 Joint Tor 2/5/8/11。T
IR-04地形 CSV文件不带列名；每行包含 1 个时间值和 693 个高度值，对应 21×33 个地形方块。T
IR-05分析 CSV支持普通 CSV 和快照 CSV；缺失或无法识别的数值按 0 处理，空行和注释行不作为数据。T
IR-06标准日志[YYYY-MM-DD HH:mm:ss.mmm.uuu] [LEVEL] [MODULE] message；解析时间精度落到毫秒。T
IR-07输出文件截图为 PNG/JPG；录像为 AVI；图表为 PNG/JPG/PDF；收集日志为 ZIP；分析结果为文本。I

9关键验收指标

编号指标目标验证
G-01三维引擎并发数X30、M20、DR02 三种引擎合计同时运行 ≤ 1 个T
G-02控制通道图像负载0 字节；图像由 GPU 窗口直接呈现I
G-03关节时间基准0.005 s/帧，200 Hz 名义采样率T
G-04录像队列最大 12 帧；积压时内存有界并报告丢帧T
G-05页面或程序退出页面启动的本地服务、三维窗口和录像任务全部关闭T
G-06日志合并顺序全部有效条目按时间戳非降序T
G-07发布物完整性主程序、3 个三维服务、日志服务、Qt/JPEG 运行时及三套模型资源齐全I

10验收准则

项目准则
需求完整性第 6～8 章全部“必须”条目通过对应验证，未通过项有明确豁免和影响分析。
三维主链路X30、M20、DR02 分别完成进入页面、模型显示、CSV 加载、播放/暂停/跳转/停止、切页释放全流程。
地形链路X30 正常地形、关闭地形、缺失文件、格式错误和跳转同步场景均通过；M20 不受地形操作影响。
分析链路普通 CSV 与快照 CSV 可加载；固定分析和自定义波形的时间范围、交互与导出结果正确。
日志链路SSH 连接、目录浏览、分页搜索、ZIP 下载、日志解析、合并、筛选、统计和导出均使用代表性数据通过。
异常链路缺文件、缺列、空文件、网络断开、辅助进程退出、保存失败不会导致主程序崩溃或永久失去交互。
部署链路在未安装 Python/Qt 的干净 Windows x64 环境安装后完成核心桌面功能冒烟测试。
一票否决：主程序因普通输入错误崩溃、页面退出后持续残留三维子进程、录像生成不可播放文件、安装包缺少核心模型或运行时，任一出现则本版本不可交付。

11风险与依赖登记

编号风险/依赖影响状态应对
R-01三维画面使用独立窗口窗口缩放、多显示器或高分辨率缩放时可能错位已缓解发布平台限定 Windows；主程序持续同步位置和大小，打开对话框时调整显示层级。
R-02三维服务体积与启动时间安装包较大，首次进入页面需要等待已识别仅在进入对应机型页面时启动服务，界面显示启动进度，离开页面后释放服务；DR02 服务不打包无关科学计算和示例资源。
R-03CSV 列名与采样率固定其他格式的 CSV 可能无法回放已缓解输入格式在第 8 章统一规定；缺少必需列时明确显示具体列名。
R-04地形包含 693 个方块首次加载和持续更新可能使画面变慢已缓解首次创建后重复使用，播放时只更新高度或颜色发生变化的方块。
R-05大型 CSV 占用内存较多超大文件可能加载失败或使界面变慢已缓解分块读取并只保存需要的列；验收时使用规定的大文件样本测试。
R-06设备密码保存在本地配置中配置文件泄露会造成账号风险已识别配置文件仅允许当前用户访问；用户手册必须说明密码保存方式。
R-07200 Hz 回放受 Windows 调度影响实际播放时长可能与理论时长存在偏差已识别验收时记录各速度档的实际时长和允许误差。
R-08功能回归项目较多修改一个模块可能影响播放、窗口或打包已识别按照第 10 章逐项执行并保存测试记录。
