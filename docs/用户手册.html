1. 产品概述与技术架构

1.1 产品定位

本工具面向四足机器狗售后与研发调试，核心用途是：把四足机器狗下位机记录下来的数据，还原成可以看、可以量的形态，从而判断四足机器狗当时的实际状态。 主要解决三类问题：

  • 看动作 —— 把关节角与姿态数据还原成三维动画，直观回放四足机器狗当时的运动；
  • 看曲线 —— 把关节角度 / 速度 / 力矩 / 温度 / 算法周期等信号画成波形，定位异常时刻；
  • 看日志 —— 从四足机器狗上把运行日志拉回本地，多文件按时间合并后筛选检索。
重要原则：三维复现与波形显示的内容完全来自数据本身，不做任何插值、平滑或修正。 画面上呈现的关节角度与机身姿态，就是四足机器狗当时记录下来的原始数值。

1.2 技术架构

本工具由两套可独立使用的前端组成，共用同一批数据格式：

组成部分技术实现说明
本地上位机 Qt 6（C++17） 主界面程序，负责界面、播放控制、曲线绘制、日志分析
三维渲染服务 Python + PyBullet 后台独立进程，负责加载 URDF 模型、按帧驱动关节、GPU 渲染； 与上位机通过本机 TCP 通信，渲染画面直接嵌入到主界面中
日志采集服务 Python + paramiko 后台独立进程，负责 SSH 连接四足机器狗、浏览与下载日志文件
Web 服务端 Go + Gin 本机 HTTP 服务（端口 9090），提供数据解析与静态资源
Web 前端 React + three.js 浏览器界面；三维复现在浏览器端用 WebGL 渲染，不依赖 PyBullet
无需任何环境依赖。Python 运行时、Qt 运行库、Go 服务、前端资源已全部打包进安装程序。 目标电脑不需要预先安装 Python、Qt、Node.js 或任何运行库，安装后即可使用。

3. 安装与启动

3.1 安装

  1. 双击 RobotReplay-2.2.1-x64-Setup.exe，按提示允许管理员权限。
  2. 若电脑上已安装旧版本，安装程序会提示是否升级；选择「是」后会自动卸载旧版再安装新版。
  3. 选择安装路径（默认 C:\Program Files\RobotReplay，可改到其他磁盘）。
  4. 勾选「在桌面创建快捷方式」，点击「安装」。
  5. 安装完成后可直接勾选「运行」启动程序。
注意：安装包约 417 MB，安装后占用磁盘约 1.5 GB（其中三维渲染服务与其依赖库约占 1.4 GB）。 请确保目标磁盘有足够空间。

3.2 启动与运行模式

双击桌面快捷方式启动，首页（图 2-1）提供两种运行模式：

  • 本地上位机 —— 直接使用 Qt 主界面的全部功能，从左侧导航栏选择即可（无需点击卡片）。
  • Web 浏览器本地服务 —— 点击后在本机启动 Web 服务并自动打开浏览器，详见第 10 章。

4. X30 三维复现

用关节数据把 X30 当时的动作在三维场景中回放出来，可叠加地形图查看足端与地面的关系。

4.1 操作步骤

  1. 进入页面。点击左侧导航栏「X30」。程序会自动启动三维渲染引擎， 等待数秒后中间区域出现 X30 模型（默认站立姿态），右侧「系统日志」显示模型加载完成的提示。
  2. 加载关节数据。点击「选择关节 CSV 文件」，选择关节数据文件。
    测试数据：test-data\关节数据和地形图\snapshot_20261212_195732.csv
    加载成功后文件框显示「已加载: 文件名」，「数据信息」栏显示总帧数与总时长 （示例数据为 56029 帧 / 04:40）。
  3. （可选）加载地形图。点击「选择地形图 CSV 文件」，选择地形数据。
    测试数据：test-data\关节数据和地形图\gridmap_20261212_195732.csv
    选择文件后，下方「播放时加载地形图」会自动勾选。如果只想看四足机器狗本体， 可以手动取消勾选，地形随即从画面中移除。
  4. 开始播放。点击底部「▶ 播放」。四足机器狗开始按数据动作，地形方块同步刷新， 右侧关节滑块实时跟随，进度条与时间同步推进。
地形图默认不加载。刚进入页面时「播放时加载地形图」是未勾选状态。 若勾选了但未选择文件、或所选文件已被删除，系统日志会给出提示并跳过地形加载，不影响关节回放。

4.3 视角与观察

  • 鼠标操作（在三维画面区域内）：左键拖动旋转视角，滚轮缩放，中键平移。
  • 视角预设：左侧「工具」栏提供「默认 / 前视 / 侧视 / 俯视」四个按钮，一键切换到标准视角。
  • 关节位置：右侧面板按 FL（前左）/ FR（前右）/ HL（后左）/ HR（后右）四条腿分组， 每条腿显示 HipX、HipY、Knee 三个关节的实时角度（弧度）。播放时滑块自动跟随； 停止后可手动拖动滑块摆姿态。
  • 小腿颜色：小腿颜色代表膝关节力矩大小，青色为低负载， 随力矩增大逐渐变为红色（图 4-1 中前右腿呈红色）， 便于快速发现受力异常的腿。
  • 系统日志：右下角滚动显示当前播放帧号、时间戳、地形图帧号和机身中心高度， 可用于核对具体数值。

4.4 截图与录像

  1. 截图：点击「截图保存」，选择保存位置，将当前三维画面存为 PNG / JPG。
  2. 录像：点击「● 开始录制」，选择保存位置（默认文件名形如 X30_20260728_143052.avi）， 按钮变为「■ 停止录制」并显示已录时长。再次点击结束录制，系统日志中会显示保存路径与帧数。
录像为 30fps 的 AVI 格式（MJPEG 编码），常见播放器均可直接播放，约 45 MB/分钟。 录制过程中可正常操作播放、暂停、切换视角。切换到其他页面或关闭程序时，录制会自动停止并保存。

5. M20 三维复现

操作方式与 X30 完全一致（选择 CSV → 播放），差异如下：

项目X30M20
机型四足轮足（每条腿末端为驱动轮）
关节面板每腿 3 个关节：HipX / HipY / Knee每腿 4 个关节：HipX / HipY / Knee / Wheel
地形图支持暂不支持（页面上的地形图按钮对 M20 不生效）
关节数据 CSV 中只记录 12 个驱动关节（每腿 HipX / HipY / Knee）， 因此 M20 面板中的 Wheel 滑块在回放过程中保持不动，属正常现象。
为避免显卡资源冲突，X30 与 M20 的三维渲染引擎不会同时运行。 从 X30 切换到 M20 时，X30 的渲染进程会自动关闭，反之亦然。 切换后需要重新加载 CSV 文件。

6. 数据分析（固定模板）

按预设模板分六类查看四足机器狗的关键信号曲线，是日常巡检的主要入口。

6.1 打开与加载

  1. 点击左侧导航栏最下方的「数据分析」，弹出独立的「数据分析」窗口。
  2. 点击左上角「加载 CSV 数据」，选择快照数据文件。
    测试数据：test-data\数据分析\JY-L3-030 2025-08-20 10-36.snapshot.csv
  3. 加载过程中显示进度百分比；完成后左侧显示文件名、总时长与「行数×列数」 （图 6-1 示例为 64.0 s / 64028 行 × 285 列）， 并自动填充「运行总时间、算法周期、通讯周期、运行总次数、算法版本、记录周期」六项状态信息。

7. 波形分析（自由配置）

不受模板限制，可任选数据列组合成图窗，适合针对某个具体问题做专项分析。

7.1 操作步骤

  1. 点击左侧导航栏「波形分析」。
  2. 点击「加载 CSV」选择数据文件。加载后左侧显示文件名、总时长与行列数， 「可用数据列」列出文件中的全部信号列（带序号与单位，如 11. Roll_Vel (rad/s)）。
  3. 在「可用数据列」中选中一个或多个列（按住 Ctrl 多选，Shift 连选）。
  4. 点击目标窗口右上角的「+」按钮，把选中的列加入该窗口；也可直接把列拖拽到窗口中。
  5. 需要更多图窗时点击「+ 添加窗口」；点「清空」清除该窗口的列，点「×」删除整个窗口。
  6. 配置完成后点击「绘 制」，右侧生成对应数量的图表，每个图表独立标注「窗口 1」「窗口 2」……

图表交互（悬停读数、右键框选缩放、底部时间窗口、自适应）与第 6.3 节完全一致。

7.2 配置方案的保存与复用

  1. 配置好窗口与数据列后，点击左下「配置管理」区的「保存」，输入方案名称（如「膝关节温度排查」）。
  2. 方案会出现在下方列表中，显示名称与保存时间。
  3. 下次使用时：加载新的 CSV → 在列表中双击方案名，即可自动恢复窗口配置并绘制。
  4. 选中方案后点击「删除」可移除该方案。

方案文件保存在程序安装目录下的 wave_configs 文件夹中，可随程序一起备份或分发给同事。

8. 日志管理 · 日志收集

8.1 添加主机

  1. 点击左侧导航栏「日志管理」，选择「日志收集」页签。
  2. 点击左下「+ 添加」，在弹出的对话框中填写主机信息，完成后点「OK」。
字段说明测试服务器填法
名称自定义备注名，便于识别ysc
地址四足机器狗或服务器 IP172.16.13.180
端口SSH 端口，一般为 2222
用户名登录账号ysc
密码登录密码ysc@2026
备注可选说明可留空
日志路径远程日志目录。每行一条，可用右侧「+」增加、「-」删除， 连接后可在顶部下拉框中切换 /home/ysc/zhangchao/log_data

8.2 连接与浏览

  1. 在左侧主机列表中单击选中要连接的主机。
  2. 点击右上角「连接」。连接成功后左上角状态由红色「● 未连接」变为绿色「● 已连接」， 主机列表中该行状态显示「在线」，并自动列出日志路径下的文件。
  3. 顶部「远程路径」下拉框可切换该主机配置的多个日志目录。
  4. 文件列表中：目录排在文件前面，双击目录进入下一级，双击「↩ .. (返回上级)」回到上层。 点击「↻ 刷新」重新读取当前目录。
  5. 右键点击某个文件 →「查看文件内容」，可在不下载的情况下分页预览：
    • 每页 1000 行，底部可翻页（首页 / 上一页 / 下一页 / 末页）；
    • 顶部输入关键字点「🔍 筛选」，只显示匹配行并标出原始行号；
    • 日志按等级自动着色：ERROR、 WARN、INFO、 DEBUG。

8.3 下载与导出

  1. 在文件列表左侧「选择」列勾选需要下载的文件，可用「☑ 全选」/「☐ 取消全选」批量操作。
  2. 在左下「导出设置」中点击「浏览...」，选择本地保存目录。
  3. 点击「⬇ 开始导出」，确认后开始下载。
  4. 进度条显示下载进度，右下「操作日志」逐条记录过程； 完成后所有文件被打包成一个 ZIP，日志中显示最终路径。
ZIP 文件命名规则：SN_板号_构型_版本_时间.zip
导出时程序会自动从四足机器狗读取序列号（/var/opt/robot/conf/MFI.toml）、 版本与构型（/var/opt/robot/release_note.json），并执行 ifconfig eth0 获取板号。
若连接的是普通服务器（非四足机器狗本体），上述文件不存在，操作日志会出现 读取 MFI.toml 失败 之类的 WARN 提示，对应字段以 unknown 代替， 文件名形如 unknown_unknown_unknown_unknown_20260728_144303.zip （见图 8-2）。这不影响文件的正常下载与打包。

9. 日志管理 · 日志分析

把多个日志文件按时间戳合并成一条完整时间线，再按条件筛选检索。

9.1 支持的日志格式

本模块解析四足机器狗标准日志格式：

[2026-04-15 09:47:57.431.797] [INFO  ] [StateMachine] start logging!!!
[2026-04-15 09:47:57.480.706] [ERROR ] [EncryptionCheck] 读取授权码文件失败
[2026-04-15 09:48:07.840.026] [INFO  ] [lio] LIO version: 1.0.13

即 [时间戳] [等级] [模块] 日志内容 四段结构。

不符合该格式的行（例如某些日志多行输出的续行、分隔线等）会被跳过， 并在分析完成的提示中统计为「未识别行」。这属正常现象，不影响其余日志的分析。

9.2 操作步骤

  1. 点击「日志管理」→「日志分析」页签。
  2. 点击「➕ 添加文件」选择一个或多个 .log 文件， 或点击「➕ 添加文件夹」批量导入整个目录。左侧列表显示文件名、修改时间与大小。
    若日志来自第 8 章导出的 ZIP，请先解压再导入。
  3. 点击「⭐ 合并分析」。程序解析全部文件并按时间戳归并，过程中显示进度。
  4. 分析完成后弹窗显示：共解析条数、筛选后条数、文件数、耗时、未识别行数； 「时间范围」会自动设为数据的实际起止时间，「模块/进程」下拉框自动填充出现过的全部模块名。
  5. 在右侧「筛选条件」中缩小范围，结果实时刷新：
    • 等级：勾选 INFO / ERROR / WARN / DEBUG； 如日志中有其他等级，在右侧输入框填写后点「+ 添加」即可新增复选框；
    • 时间范围：设定起止时刻；
    • 关键字：支持正则表达式，回车生效；
    • 模块/进程：从下拉框选择单个模块，或选「全部」。

9.3 结果查看

功能说明
结果表格按时间顺序显示：序号、时间戳、等级、进程/模块、来源文件、日志消息。 ERROR 行标红，WARN 行标黄，便于一眼定位
搜索底部输入关键字，「▼ 下一个」/「▲ 上一个」逐条跳转并高亮， 搜完一轮会提示「[已循环]」
时间轴播放「◀◀ 前帧」/「▶ 播放」/「后帧 ▶▶」 按日志真实时间间隔逐条推进，速度可选（0.5x ~ 最快）； 下方滑块显示当前时刻在整段日志中的位置，便于观察事件发生的先后节奏

10. Web 浏览器模式

除本地上位机外，本工具还提供浏览器界面，操作更轻量，也便于在同一局域网内的其他电脑上查看。

10.1 启动

  1. 在首页点击右侧卡片「Web 浏览器本地服务」。
  2. 程序在本机启动 Web 服务，并自动打开默认浏览器访问 http://localhost:9090。
  3. 若浏览器未自动打开，可手动输入该地址。推荐使用 Chrome 或 Edge。
服务只会启动一个实例：若已在运行，再次点击卡片只会重新打开浏览器页面，不会重复启动。 关闭上位机程序时，Web 服务会自动一并关闭，不会残留后台进程。

Web 端左侧共 4 个菜单：

菜单功能与桌面端的差异
首页功能入口导航—
三维复现X30 三维运动回放 在浏览器中用 WebGL 渲染，不依赖 PyBullet；暂不支持地形图、录像与 M20
日志收集SSH 连接、浏览、下载日志操作流程与桌面端一致
日志分析导入日志文件后合并筛选额外提供统计卡片，一眼看到各等级条数

10.2 Web 端三维复现

  1. 左侧菜单点击「三维复现」，等待页面加载 X30 模型（首次约需数秒）。
  2. 点击「选择关节 CSV 文件」，选择关节数据文件（与桌面端使用同一份数据）。
  3. 加载完成后「数据信息」显示总帧数、总时长与状态，此时四足机器狗仍保持默认站姿。
  4. 点击底部「播放」开始回放。
  • 视角：鼠标左键拖动旋转，滚轮缩放，右键拖动平移；左侧「视角」栏提供 「默认 / 前视 / 侧视 / 俯视」四个预设。
  • 关节位置：左侧「X30 关节位置 (rad)」面板按四条腿分组，实时显示 12 个关节的角度值。
  • 播放控制：底部为 暂停 / 停止 / 速度下拉框（0.5x ~ 2x）/ 循环， 进度条可拖动跳转，右下角显示「帧：当前 / 总数」。
  • 截图：点击左侧「截图保存」把当前画面下载为 PNG。

10.3 Web 端日志收集

  1. 左侧菜单点击「日志收集」。
  2. 点击「主机管理」右上角「+ 添加」，填写主机信息（字段与第 8.1 节完全相同）。
  3. 主机卡片右侧三个图标依次为：编辑（✏）、连接（🔗）、删除（🗑）。 点击连接图标，卡片左侧圆点变绿表示已连接。
  4. 在右侧「远程文件浏览」中选择文件，勾选后下载。
  5. 页面底部「操作日志」可展开/收起，记录每一步操作及结果。

10.4 Web 端日志分析

  1. 左侧菜单点击「日志分析」。
  2. 点击右上角「添加文件」选择 .log 文件，可多选； 已添加的文件以标签形式列出（带大小），点标签上的 ✕ 可移除。
  3. 点击「解析日志」开始分析。
  4. 解析完成后显示统计卡片：总条数、ERROR、INFO、WARN、未识别、时间范围、模块数 （图 10-4 示例为 136,969 条 / 3 条 ERROR / 19 个模块）。
  5. 在「筛选条件」中按日志等级、关键字（支持正则）、模块名、日期范围、来源文件过滤， 点「🔍 筛选」应用。
  6. 点击「导出合并」可把结果导出为单个文件。
Web 端日志表格中的等级与模块以彩色标签显示，比桌面端更易区分； 右上角「⊤ 顶部」按钮可快速回到列表开头。

11.2 CSV 数据格式要求

三维复现用（关节数据）

必须包含以下列，缺任意一项都无法回放：

关节角度Joint Pos 0 ~ Joint Pos 11，共 12 列，单位弧度
顺序为 FL、FR、HL、HR 四条腿，每腿依次 HipX、HipY、Knee
机身姿态IMU roll、IMU pitch、IMU yaw，单位度
关节力矩Joint Tor 2、5、8、11（膝关节）， 用于小腿着色；缺失时不着色，不影响回放

采样率按 200 Hz 处理（每帧 5 毫秒）。

数据分析 / 波形分析用（快照数据）

支持两种格式，程序自动识别：

  • 快照格式（推荐）：第 1 行为信息名称，第 2 行为信息数值，第 3 行为数据列名，第 4 行起为数据。 程序会自动从 Alg_Period (us) 反算真实采样率。
  • 普通格式：第 1 行为列名，其后为数据。

地形图数据

每行 1 个时间戳 + 693 个高度值（21 行 × 33 列网格），无表头。 地形图的帧数与关节数据可以不同，播放时按时间对齐。

11.3 常见问题

现象原因与处理
点击 X30 后中间区域长时间空白 三维渲染引擎首次启动需要数秒加载模型。若超过 30 秒仍无画面， 请查看右侧「系统日志」的报错信息

播放时地形图没有出现 确认已勾选「播放时加载地形图」且已选择地形图文件； 文件框显示「已选择(未启用)」即表示当前未勾选。查看系统日志中的提示信息
某个图表一直空白 该 CSV 未记录对应信号，左侧会提示「暂无数据」，属正常情况
笔记本上界面显示不全 左侧控制面板可上下滚动；「数据分析」窗口会自动适配屏幕高度。 建议使用 1920×1080 及以上分辨率以获得最佳体验
