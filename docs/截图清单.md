# docs 目录说明

| 文件 | 说明 |
|---|---|
| `用户手册.html` | 完整用户手册，双击用浏览器打开 |
| `images\` | 手册引用的 12 张截图 |

## 导出 PDF

1. 浏览器打开 `用户手册.html`
2. 按 `Ctrl+P`
3. 目标选「**另存为 PDF**」
4. **务必勾选「背景图形」**，否则表格底色和提示框颜色会全部丢失
5. 保存
